# Hanzi Movie Method — Personal Mnemonic System

This document records the learner's personal mnemonic matrix. Use these associations consistently when creating Mandarin vocabulary mnemonics and Anki cards.

## 1. Core construction sequence

For a word or syllable, build the pronunciation/meaning movie using:

1. Pinyin initial → person/character
2. Pinyin final → the assigned location or scene
3. Tone → the assigned position within that location
4. Combine the elements into one vivid, unusual action that encodes the word's meaning.
5. Keep the actual Hanzi structure and radical separate from mnemonic imagery. A visual resemblance is a memory cue, not a claim about etymology.

The canonical sequence in the existing project README is:

`initial → person/character → final → location → tone → position → movie → Hanzi/meaning`

When a syllable has no initial, use the zero-initial character (Ø).

## 2. Geography and tone-position locations

The location progression is:

**Poland → Great Britain (UK) → Mexico → Schools**

The first three groups are apartment/building locations, in this order:
- Poland
- Great Britain / UK

The school locations follow the apartment groups.

## 9. Rules for creating new vocabulary cards

For every new word:

1. Check its real Mandarin pinyin, tone, meaning, and common usage.
2. Split the syllable into its actual initial and final. Use Ø when there is no initial.
3. Select the initial's person/character from the appropriate list (male, female, fictional, or Greek-god anchor).
4. Select the final's location from the ordered location matrix.
5. Place the scene at the position corresponding to the word's actual tone.
6. Create a vivid, memorable interaction that connects the scene to the word's meaning.
7. For multi-syllable words, construct and connect the syllable scenes without changing their tones.
8. Add at least one natural example sentence, preferably useful in a real travel situation.
9. Keep the radical and visual components factually separate from the mnemonic story.
10. Add the card to the Anki source and include the mnemonic fields, pinyin, tone, meaning, Hanzi, example, and any supporting image.

**Important:** Mnemonics are retrieval cues. They must never override correct pronunciation, tone, meaning, grammar, or actual character etymology.
